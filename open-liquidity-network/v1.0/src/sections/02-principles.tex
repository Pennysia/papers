\section{Design Principles}\label{sec:principles}

The following principles guide implementation, including the choices that remain open.

\begin{itemize}[leftmargin=1.5em]
  \item \textbf{Venue independence.} Providers integrate through a common executable-quote interface. Pennysia operates the access network and relies on external venues for liquidity and financial services.

  \item \textbf{User-controlled assets.} Pennysia holds no pooled user balances and cannot sign on a user's behalf. Users retain control of their wallets independently of the network.

  \item \textbf{Signature-based execution.} Users authorize the terms of an order. The network arranges transaction submission and gas payment on the required chains.

  \item \textbf{Execution-based ranking.} Quotes compete on output after costs, adjusted for fill probability. Listing is free, and venues cannot purchase ranking priority.

  \item \textbf{Optional verification.} Users can access permissionless venues without verification and opt into verification for eligible regulated services.

  \item \textbf{Disclosed costs.} Quotes include all execution costs. Any surplus fee applies only to output above the quoted amount. Access requires no native network token.
\end{itemize}
