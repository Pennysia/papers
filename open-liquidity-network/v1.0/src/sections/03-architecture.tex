\section{System Overview}\label{sec:architecture}

Four layers, each with one job (Figure~\ref{fig:layers}). Users interact only with the top. Venues integrate only with the middle.

\textbf{Identity} provisions non-custodial embedded wallets per chain family from a Web2 login (email, Google, Apple); external wallets connect for the same surface (Section~\ref{sec:account}). The \textbf{quote market} fans every order out in parallel to all venues in the user's enabled lanes and normalizes and ranks the quotes (Section~\ref{sec:quote-market}). The \textbf{execution fabric} carries a signed order to settlement over three rails (atomic routes, intent rails, venue rails) under one set of guarantees (Section~\ref{sec:execution}). The \textbf{experience} presents a unified balance, one trade ticket, and one status line, with chains visible only on request; portfolio and verification state also live here (Section~\ref{sec:compliance}).

Every order walks the same loop (quote, sign, execute, verify) regardless of which rail carries it. Figure~\ref{fig:participants} draws the boundary each participant sees.
